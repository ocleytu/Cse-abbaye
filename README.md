# Site du CSE — Abbaye des Vaux-de-Cernay

Site des salariés : demandes de prise en charge, Gazette, agenda, budget, avantages, boîte à idées, élus.

- Tout le site tient dans `index.html` (images incluses).
- `netlify.toml` : publication telle quelle sur Netlify, sans étape de build. Le site n'est pas indexé par les moteurs de recherche (`noindex`).
- Chaque modification passe par un commit : l'historique permet de revenir à une version précédente.

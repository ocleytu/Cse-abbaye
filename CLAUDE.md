# Instruções para o Claude

## Imagens

Sempre que o pedido envolver imagem (criar, gerar, editar, ilustrar, post, banner, logo etc.):

1. **Gerar a imagem** com o Higgsfield (modelo padrão GPT Image) ou com a API da OpenAI
   (via Codex, se a conta da API tiver crédito).
2. **Ou entregar um prompt pronto para colar no ChatGPT**, completo: assunto, composição,
   estilo, luz, cores, formato/proporção, texto exato que aparece na imagem (entre aspas)
   e o que evitar.

Em geral, faça os dois: gere a imagem e entregue também o prompt para o ChatGPT,
num bloco de código fácil de copiar. Antes de gastar créditos, confirme o pedido
se ele estiver vago.
